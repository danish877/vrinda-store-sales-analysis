📊 Vrinda Store Sales Analysis — Excel

📌 Project Overview

This project analyzes Vrinda Store sales data using Microsoft Excel.

The analysis focuses on understanding sales performance, customer demographics, order status, sales channels, and state-wise sales. The project uses Pivot Tables, Pivot Charts, Slicers, data cleaning, and dashboarding to turn raw sales data into an interactive Excel report.

«Learning Note: This is a tutorial-guided project completed as part of my practical learning journey in Data Analytics. The project helped me practice Excel-based data cleaning, analysis, visualization, and dashboard creation.»

---

🎯 Project Objectives

The main objectives of this project were to:

- Analyze monthly sales and order trends
- Compare sales between men and women customers
- Understand different order statuses
- Identify states with higher sales
- Analyze customers by age group and gender
- Understand sales/order contribution across different channels
- Build an interactive Excel dashboard for reporting

🔄 Analysis Workflow

The project follows this general workflow:

Raw Data → Data Cleaning & Preparation → Pivot Tables → Pivot Charts → Analysis → Dashboard

1. Data Preparation

The raw sales data was organized and prepared for analysis in Excel.

The "Vrinda Store" sheet contains the detailed transactional data used to create the different analyses and dashboard components.

2. Sales & Orders Analysis

The Sales Vs Orders sheet analyzes monthly sales amount and order count.

The analysis covers all 12 months, from January to December, allowing monthly sales and order trends to be compared.

3. Gender Analysis

The Men Vs Women sheet compares sales amount by gender.

The analysis shows:

- Men: ₹7,613,604
- Women: ₹13,562,773

4. Order Status Analysis

The Order Status sheet analyzes the number of orders by status.

The categories include:

- Delivered
- Returned
- Cancelled
- Refunded

The analysis contains:

- Delivered: 28,641
- Returned: 1,045
- Cancelled: 844
- Refunded: 517

5. State-wise Sales Analysis

The Top States sheet analyzes sales amount by state.

The sheet highlights the top five states by sales amount:

- Maharashtra
- Karnataka
- Uttar Pradesh
- Telangana
- Tamil Nadu

6. Age & Gender Analysis

The Age In Gender sheet compares customer order contribution across:

- Adult
- Senior
- Teenager

and separates the analysis between:

- Men
- Women

7. Sales Channel Analysis

The Channels sheet analyzes order contribution across different sales channels.

The channels included are:

- Amazon
- Flipkart
- Myntra
- Ajio
- Meesho
- Nalli
- Others
